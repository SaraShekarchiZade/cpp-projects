# Fekre Bakar (Creative Mind) Game

## Description
Fekre Bakar is a number-guessing game where the machine generates a random number of 4-9 digits. 
The player tries to guess the number within 12 attempts. Feedback is provided for correct digits 
and positions. The game allows settings for repeated digits, guess history, and score calculation.

## Features
- User registration with password
- Game settings: number length, repeated digits, show history
- Gameplay with attempts, feedback, and scoring
- Scoreboard display sorted by score

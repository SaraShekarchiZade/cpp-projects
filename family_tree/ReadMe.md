# Family Tree Project

This C++ project models a **family tree** and provides operations such as:

1. Displaying couples with no blood relation.
2. Displaying relatives of a specific type.
3. Finding the person with the most descendants.
4. Finding the closest relation between two individuals.

## Folder Structure
- `src/` - C++ source code
- `data/` - Sample input/output
- `Report/` - Project report PDF

## How to Compile
```bash
g++ src/main.cpp -o FamilyTree
./FamilyTree

# Ant City Reproduction Encoder & Decoder

## Description
This project simulates ant reproduction in a city where workers and queens generate children based on substring-prefix matching. The project consists of:

- **Encoder:** Reads worker and queen ants, filters foreign ants, and stores the order of children efficiently.
- **Decoder:** Reconstructs the original order of children from the encoded file.

## Files
- `Encoder.cpp`: C++ program that filters and encodes children ants.
- `Decoder.cpp`: C++ program that decodes and prints children in order.
- `txt.parents`: Input file containing queen and worker ants.
- `order`: Binary file storing encoded children (generated by Encoder).
